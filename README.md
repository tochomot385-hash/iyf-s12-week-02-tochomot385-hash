## What I Built

A 5-page responsive portfolio using only HTML & CSS.
No JavaScript, no frameworks.

## What I Learned

- CSS Box Model - Content, Padding, Border, Margin
- Flexbox - Nav, Hero, Footer layout
- CSS Grid - Projects grid (1 col mobile, 2 col tablet, 3 col desktop)
- Responsive Design - Tested at 320px, 768px, 1024px
- No horizontal scroll on mobile

## Files

- `index.html` - Home page, Hero + Intro
- `about.html` - About me, Skills
- `projects.html` - 6 projects in CSS Grid
- `contact.html` - Contact form
- `box-model-practice.html` - Box Model practice
- `style.css` - All styles, Flexbox + Grid, Media Queries

## How To Check

1. Open Live Demo in incognito / private window
2. Resize to 320px - 1 column, no horizontal scroll
3. Resize to 768px - 2 columns
4. Resize to 1024px - 3 columns
5. Click all pages - Nav works on every page
6. Check Contact form - Labels + inputs aligned
